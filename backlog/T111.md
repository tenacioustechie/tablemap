## Goal
The players see the turn order: a compact strip along one edge of the TV with names and the current turn highlighted, toggleable by the DM per session, and a ring around the current entry's token on the map. Plan: `docs/plans/2026-09-v2-vision-and-depth.md`, ADR 0026.

## Design
- `PlayerPresentation.initiativeStrip: boolean` (DM-only presentation like `overview`; default false; `isPlayerPresentation` strict as usual; equality/clone updated). Toolbar toggle **Turn strip** (`initiative-strip-toggle`, `aria-pressed`) next to blackout/splash; also in the Turns tab.
- Player render: a DOM strip (`player-initiative-strip`) inside the existing `Rotated` box so it sits along the TV's top edge whichever way the view is turned; entries as chips (`player-initiative-entry`, current `data-current="true"`), "Round n" at the end; hidden entirely when the list is empty or the toggle is off. It never covers more than 8 % of the display height; long lists scroll horizontally with the current chip kept in view.
- Ring: `TokenLayer` (shared stage) draws a ring around the token linked to the current entry when that token is visible in that view (player: respects hidden/fogged rules; DM: always). This replaces T110's DM-only ring. Ring is drawn on both views from shared data; no presentation flag.
- Blackout and splash still cover the strip (it lives below them in z-order).

## Acceptance criteria
- [ ] Toggle on: strip appears on the TV with the current entry highlighted; **Next** on the DM moves the highlight within one delta; toggle off hides it
- [ ] Rotating the player view keeps the strip readable along the top edge
- [ ] The current token's ring shows on the TV only when the token itself is visible there
- [ ] Blackout covers the strip

## Test requirements
- Unit: `state/calibration.test.ts` (field, equality), `sync.test.ts` (crosses), `player/usePlayerSync.test.tsx` (strip on/off, current chip, empty list, rotation attribute), `map/TokenLayer` test (ring rules per view).
- E2E: `e2e/initiative.spec.ts` — build a list, toggle the strip, `Next` on the DM updates the player chip; blackout covers it.
- Docs: user guide "Running initiative" (players' side), architecture (presentation field, strip, ring), ADR 0026 completed.
