## Goal
Zustand store as single source of truth in the DM window. Typed, versioned message schema in src/state/sync.ts: hello/snapshot/delta. Player window requests snapshot on load, applies deltas, renders store state read-only.

## Acceptance criteria
- [ ] All DM->player traffic goes through sync.ts message types; protocol version constant included in every message
- [ ] Player reconnect (reload player window) recovers full state via snapshot
- [ ] No player->DM mutations exist

## Test requirements
- Unit: encode/decode round-trip for every message type; reducer applies deltas = applying snapshot. E2E: change a value in DM page, assert player page reflects it.
