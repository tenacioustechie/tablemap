## Goal
Stop the Esc–drag–re-arm dance: the DM can pan the canvas while any tool is armed, and every tool, mode and tab has a single-key shortcut listed on a `?` overlay. Design: `docs/plans/2026-09-dm-usability.md` §3.4.

## Design
- **Pan override** in `DmCanvas`: a middle-button drag, or a drag while **Space** is held, pans the DM canvas whatever tool is armed (the tool's gesture machine never sees those pointer events; a gesture in progress is left as it was). Wheel zoom already works during tools. Cursor shows "grab" while Space is held.
- **Shortcuts** (ignored inside text fields, `isEditableTarget` as today; no modifier): `1`–`5` open the tabs in order; `V` stop the tool; fog `R` reveal mode, `H` hide mode, `B` brush, `X` rectangle, `L` lasso, `[` / `]` brush radius −/+ step; draw `P` pen, `E` eraser; `N` place note; `G` align grid; `?` toggle the cheat sheet. Existing Esc, Ctrl/Cmd+Z/Shift+Z/Y unchanged. A fog/draw key arms that tool and opens its tab if it is not the current one.
- Pure keymap `dm/shortcuts.ts`: `shortcutFor(event) → Command | null` and `SHORTCUTS` (the table the overlay and the chip render from). `DmView` turns commands into the existing `selectFogTool` / `selectDrawMode` / `toggleTool` / tab calls.
- **Cheat sheet** overlay (`data-testid="shortcut-help"`): a dismissable modal listing every shortcut and the mouse gestures (wheel, drag, Alt-click, middle/Space drag), rendered from `SHORTCUTS` so it cannot drift. Also opened from a `?` button in the toolbar.
- The tool status chip (T016) shows the armed tool's key.

## Acceptance criteria
- [ ] With the reveal brush armed, a Space-drag and a middle-drag pan the DM canvas without painting; releasing continues brushing
- [ ] Every listed key does what the table says; none fires inside the campaign-name input or a note textarea
- [ ] `?` shows a list that matches `SHORTCUTS` exactly; Esc closes it (and only it, when it is open)

## Test requirements
- Unit: `dm/shortcuts.test.ts` (each key → command; modifiers and editable targets → null), `dm/DmView.test.tsx` (keys arm tools/switch tabs; `?` overlay contents equal `SHORTCUTS`; Esc precedence), `map/fogGesture.test.ts` unchanged.
- E2E: extend `e2e/fog.spec.ts`: arm the brush by key, Space-drag pans (DM viewport attributes move, fog op count unchanged), then a normal drag reveals.
- Docs: user guide §9 keyboard table regenerated from the same list (the docs test may check the labels), architecture (DmCanvas pan override, `shortcuts.ts`), ADR 0020 amended or a short ADR 0022 if the pan-override design needs justification.
