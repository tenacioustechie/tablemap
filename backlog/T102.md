## Goal
Draw, edit and delete walls and doors on the DM canvas from the Walls tab: a wall polyline tool, a door tool, grid-corner snapping, select-and-delete. Plan: `docs/plans/2026-09-v2-vision-and-depth.md`.

## Design
- Tools (mutually exclusive with the other canvas tools via `DmTool`; add `"wall"`): **Wall** — click places vertices, each click after the first commits one segment (`map/wall-set`), double-click or Esc ends the polyline; **Door** — click-drag one segment, committed on release as a closed door. Both snap to grid corners when **Snap to grid** is on (default on; cell corners from `GridGeometry`), with a snap threshold of 12 screen px; Shift disables snapping for that click.
- Pure gesture machine `map/wallGesture.ts` (`reduceWallGesture(state, event)`; `idle → drawing(vertices) …`) with the preview segment; the canvas feeds it map-space pointer events like the fog and alignment tools do.
- Selection: with no tool armed, clicking a wall or door on the DM canvas selects it (highlight); **Delete/Backspace** or the panel's delete removes it; drag an endpoint to move it (`map/wall-set` on release). The tool status chip (T016) and shortcuts (T018: `W` wall, `D` door) cover the new tools.
- Panel (Walls tab): tool buttons (`wall-tool-wall`, `wall-tool-door`, `wall-stop`), snap checkbox (`wall-snap`), counts of walls and doors, the selected segment's kind and length in cells, delete, and T101's clear.
- Wall edits are not undoable in this task (say so in the guide); a later task may add a history.

## Acceptance criteria
- [ ] Draw a four-segment room and one door in under a minute with the mouse; segments snap to corners when snapping is on
- [ ] Select, move an endpoint, delete: the store and the player mirror follow
- [ ] Esc ends the polyline without a dangling segment; switching maps ends the tool
