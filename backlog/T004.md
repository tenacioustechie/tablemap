## Goal
Drag-drop or file-pick PNG/JPG/WebP onto /dm to create a map. Konva stage renders the image; DM pan/zoom (wheel + drag). Map list per campaign with thumbnails, duplicate/rename/delete, active-map switch synced to player.

## Acceptance criteria
- [ ] Imported image persists (blob in IndexedDB) and re-renders after reload
- [ ] Switching active map updates the player window
- [ ] Blank gridded map option (solid colour, chosen size)

## Test requirements
- Unit: import pipeline (file -> blob -> map record). E2E: import fixture image, appears on both pages; scene switch reflected on player page.
