## Goal
Token layer: coloured discs with letter/number badge, or image tokens. Sizes 1x1..4x4, snap-to-grid toggle, DM drag. Per-token hiddenFromPlayers flag. Player render hides: flagged tokens, and any token whose cell is fogged.

## Acceptance criteria
- [ ] Fog test: token under fog invisible on player, visible dimmed context on DM
- [ ] Token state persists and syncs

## Test requirements
