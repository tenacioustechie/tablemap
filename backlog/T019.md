## Goal
Finish the DM usability pass: a wider, collapsible sidebar; setup-once forms tucked away; the session's key facts in the toolbar; and the TV rotation remembered per display (the follow-up ADR 0014 named). Design: `docs/plans/2026-09-dm-usability.md` §3.5.

## Design
- Sidebar **300 px**, with a collapse/expand button in the tab strip (`data-testid="sidebar-toggle"`); collapsed shows only the tab icons/letters and clicking one expands. Remembered in `localStorage` next to the tab (`tablemap.dm.sidebar`).
- **Blank gridded map** form behind a "New blank map" disclosure (`data-testid="blank-map-disclosure"`), collapsed by default; the map import stays visible. Calibration's "From the TV's size" fieldset likewise behind a disclosure once a calibration exists.
- Toolbar gains, between the splash button and the player-window status: the **active map's name** (`data-testid="active-map-name"`; "No map shown" otherwise) and a **calibration chip** (`data-testid="calibration-chip"`: "1 inch = 96 px/in" style text from the current calibration and cell unit, or "Not calibrated"; click opens the Table tab).
- **TV rotation per display**: `DisplayCalibration` (or a sibling record under the same display key in settings) gains `rotation`; `calibrationSession` saves it whenever `presentation.rotation` changes for a known display and applies the stored value when a display reports (`setPlayerDisplay`). Unknown display → 0 as today. Clearing the calibration does not clear the rotation. Export/import unaffected (settings are per machine, ADR 0011).

## Acceptance criteria
- [ ] Sidebar collapse/expand and width survive reload; canvas resizes with it
- [ ] Blank-map and TV-size forms are hidden until opened; every existing test that uses them opens the disclosure first (helper), no test weakened
- [ ] Toolbar shows the active map name and the calibration state; both update live
- [ ] Rotate the player view 90°, reload the DM window, reconnect the player: rotation is 90° again for that display and 0° for a different display
