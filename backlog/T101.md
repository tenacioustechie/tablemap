## Goal
Add walls and doors to the scene as free segments in map pixels, shared with the player (data only, never drawn there), turned by scene rotation, exported and imported. No drawing tools yet (T102): this task is the model, the ops, the persistence and a read-only render on the DM canvas. Plan: `docs/plans/2026-09-v2-vision-and-depth.md`.

## Design
- Schema **v9**: `MapScene.walls: WallSegment[]` (migration v8→v9 adds `[]`).
  `WallSegment = { id: string; x1: number; y1: number; x2: number; y2: number; kind: "wall" } | { id; x1; y1; x2; y2; kind: "door"; open: boolean }` in `state/walls.ts` with guards, `isWallSegment`, `isWallPatch`, `segmentLength`, `wallsEqual`.
- Ops (`shared.ts`): `map/wall-set { id, segment }` (insert or replace by segment id), `map/wall-remove { id, segmentId }`, `map/walls-clear { id }`. Doors' `open` changes through `map/wall-set` too (T103 adds the convenience). All go to the player unfiltered (`opsForPlayer` passes them; the player needs walls for T107).
- `rotateScene` (T017) turns both endpoints of every segment.
- `referencedAssetIds` unchanged (walls carry no assets). Archive round-trip carries the field.
- DM render: `DmCanvas` draws walls in the controls layer (`WallLayer` in `dm/`): walls as 3 px lines in a distinct colour, doors as dashed lines (closed) or a thin outline (open), `listening={false}` for now. The player stage has no wall drawing code (add a boundary test that `src/map/` and `src/player/` never import `WallLayer`).
- Walls tab placeholder: a **Walls** tab (`dm-tab-walls`, after Draw; T016's `SidebarTabs` gains it, T018's tab shortcuts extend to `6`) showing the count and a **Clear walls** button with inline confirm. Drawing tools arrive in T102.

## Acceptance criteria
- [ ] A scene with walls reloads, exports and imports byte-equal; a v8 document loads with `walls: []`
- [ ] Rotating a map turns every wall with it (4×90° = identity)
- [ ] Walls appear on the DM canvas and never on the player stage
- [ ] The sync layer delivers wall ops to the player mirror

## Test requirements
- Unit: `state/walls.test.ts` (guards, equality), `shared.test.ts` (three ops, unknown segment id is a no-op), `campaign.test.ts` (v8→v9), `sceneRotation.test.ts` (walls), `campaignArchive.test.ts` (round trip), `sync.test.ts`/`mirror.test.ts` (ops cross), `player/boundary.test.ts` (no wall render import), `dm/DmCanvas`-level test for the layer's node count.
- Docs: architecture (model, ops, DM layer, schema history), user guide §2 stub "Walls and doors" (finished in T102), ADR 0024 "Walls as free segments shared with the player" (why segments, why on the wire, why v3 reuses them).
